# drift rack — realtime guitar fx

ブラウザだけで動くリアルタイム・ギターエフェクトラック(Web Audio API)。
Fireface等のオーディオインターフェースからのギター入力に、GRM Tools的な
5つのエフェクトを個別にオン/オフ・ミックスしながらかけられ、パラメータ
ごとにランダムウォークで自動的に動かすこともできます。

## Mac + Fireface での使い方

1. RME TotalMix等でFirefaceの入力にギターを立ち上げ、Macの「サウンド」
   設定の入力デバイスをFirefaceにしておく。
2. このフォルダをローカルサーバで配信して開く(`file://` はマイク権限が
   得られないブラウザがあるため避ける)。

   ```sh
   cd guitar-fx
   python3 -m http.server 8000
   ```

   ブラウザで `http://localhost:8000` を開く。
3. 「マイク接続 & 起動」を押す。ブラウザの許可ダイアログが出るので
   「許可」を選ぶ(最初は既定の入力デバイスで開始します)。
4. 起動すると下の「オーディオ入力デバイス」プルダウンに実際のデバイス名が
   並ぶので、そこでFirefaceの入力チャンネル(または内蔵マイク)を選ぶと、
   演奏を止めずにその場で入力デバイスが切り替わる。
5. 各エフェクトパネルの丸いLEDでオン/オフ、Mixフェーダーで各エフェクトの
   混ざり具合を調整。「R」チェックを入れたパラメータだけがランダムウォーク
   で自動的に動く(複数同時でも、1つだけでも可)。
6. 「🎲 全ランダムを再抽選」でランダム対象パラメータの行き先を即座に
   引き直せる。「Random Speed」でランダムの動く速さ全体を調整。
7. 「● 録音開始」でマスター出力(エフェクト込み)を録音、停止後にその場で
   再生・ダウンロードできる。

## うまく動かないとき

画面下部の「診断ログ」に、何が起きているか(権限の状態・成功/失敗の
理由)がそのまま表示されます。まずそこを見てください。よくある原因:

- **「マイク接続 & 起動」を押しても許可ダイアログが出ない/ずっと
  「マイクへのアクセスを許可してください…」のまま** → macOSの
  「システム設定 → プライバシーとセキュリティ → マイク」を開き、使っている
  ブラウザ本体(Google Chrome / Firefox)にチェックが入っているか確認する。
  入っていなければONにしてブラウザを完全に再起動してからやり直す。12秒で
  自動的にタイムアウトしてボタンは復帰します。
- **「マイクの権限が拒否されています」と出る** → アドレスバー左のサイト
  情報アイコン(鍵/ⓘ)を開き、マイクの設定を「許可」に変更してページを
  再読み込みする。
- **デバイスが他アプリで使用中と出る** → RME TotalMixや他のブラウザタブ、
  他のビデオ会議アプリなどFirefaceを掴んでいるものを閉じる。
- それでも直らない場合は診断ログの内容をそのまま伝えてください。

## エフェクト一覧

- **タイムマシン・ルーパー** — 数秒〜30秒前の演奏を呼び戻すディレイ。
  フリーズで無限ループ、ジャンプボタンでランダムな時間に飛ぶ。
- **16秒ディレイ(進化版)** — Electro-Harmonix 16 Second Digital Delayの
  「時間を動かすとピッチも動く」BBD的挙動を、時間パラメータのランダム
  ウォークで再現。
- **GRMディレイ** — Attack(反復音の立ち上がり速度)とSustain(尾の長さ)
  で反復のエンベロープを彫刻するディレイ。
- **ランダムスイッチ** — 不規則な間隔で信号を断片化するカオス・ゲート。
- **ドリフト・ビブラート** — ピッチのビブラートのレートと深さが演奏中に
  じわじわ動き続ける。

すべて内部はWeb Audio APIのみで完結しており、外部ライブラリへの依存は
ありません。
