# drift rack — realtime guitar fx

ブラウザだけで動くリアルタイム・ギターエフェクトラック(Web Audio API)。
Fireface等のオーディオインターフェースからのギター入力に、GRM Tools的な
複数のエフェクト(4トラックの空間ディレイ・バンクを含む)を個別にオン/
オフ・ミックスしながらかけられ、パラメータ
ごとにランダムウォークで自動的に動かすこともできます。

## Mac + Fireface での使い方

1. RME TotalMix等でFirefaceの入力にギターを立ち上げ、Macの「サウンド」
   設定の入力デバイスをFirefaceにしておく。
2. このフォルダをローカルサーバで配信して開く(`file://` はマイク権限が
   得られないブラウザがあるため避ける)。

   ```sh
   cd guitar-fx
   python3 -m http.server 8000
   ```

   ブラウザで `http://localhost:8000` を開く。
3. **マイクを繋ぐ前に**まず「0. 出力の確認」の「🔊 出力テスト音を鳴らす」を
   押す。これはマイク権限なしで鳴る単純な440Hzの音で、入力とは完全に独立
   した経路。**これが聞こえない場合、原因はこのアプリのコードではなく
   Mac/ブラウザ側の出力ルーティング**(下の「うまく動かないとき」参照)。
4. 聞こえたら「1. 入力設定」の「マイク接続 & 起動」を押す。ブラウザの許可
   ダイアログが出るので「許可」を選ぶ(最初は既定の入力デバイスで開始)。
5. 起動すると「オーディオ入力デバイス」プルダウンに実際のデバイス名が
   並ぶので、そこでFirefaceの入力チャンネル(または内蔵マイク)を選ぶと、
   演奏を止めずにその場で入力デバイスが切り替わる。対応ブラウザ(主に
   Chrome)では「出力デバイス」プルダウンで出力側も直接指定できる。
6. 各エフェクトパネルの丸いLEDでオン/オフ、Mixフェーダーで各エフェクトの
   混ざり具合を調整。「R」チェックを入れたパラメータだけがランダムウォーク
   で自動的に動く(複数同時でも、1つだけでも可)。
7. 「🎲 全ランダムを再抽選」でランダム対象パラメータの行き先を即座に
   引き直せる。「Random Speed」でランダムの動く速さ全体を調整。
8. 「● 録音開始」でマスター出力(エフェクト込み)を録音、停止後にその場で
   再生・ダウンロードできる。

## うまく動かないとき

画面下部の「診断ログ」に、何が起きているか(権限の状態・成功/失敗の
理由)がそのまま表示されます。まずそこを見てください。**「出力テスト音」
が聞こえるか」で、問題が入力側か出力側かをまず切り分けてください。**

### 出力テスト音が聞こえない(音が出ない)
これはこのアプリのコードの問題ではなく、Mac/ブラウザの出力ルーティングの
問題です。
- Macの「システム設定 → サウンド → 出力」で、聞きたい機器(Firefaceの
  ヘッドホン出力、内蔵スピーカー等)が選ばれているか確認する。
- Firefaceを使っている場合、TotalMixで**このブラウザタブの音**(コンピュー
  タの再生音)が、聞いているモニター出力にルーティングされているか確認
  する。「Direct Monitoring」がオンだとギターの生音は聞こえても、ブラウザ
  で処理した後の音はまた別経路なので、それだけでは聞こえない。
- ブラウザ自体がタブミュートになっていないか(Chromeはタブを右クリック
  → ミュート解除)、システム音量・アプリ別音量が0になっていないか確認。
- Chromeなど対応ブラウザでは、画面の「出力デバイス」プルダウンで直接
  出力先を指定できます。

### マイク接続がうまくいかない(入力できない/選べない)
- **「マイク接続 & 起動」を押しても許可ダイアログが出ない/ずっと
  「マイクへのアクセスを許可してください…」のまま** → macOSの
  「システム設定 → プライバシーとセキュリティ → マイク」を開き、使っている
  ブラウザ本体(Google Chrome / Firefox)にチェックが入っているか確認する。
  入っていなければONにしてブラウザを完全に再起動してからやり直す。12秒で
  自動的にタイムアウトしてボタンは復帰します。
- **「マイクの権限が拒否されています」と出る** → アドレスバー左のサイト
  情報アイコン(鍵/ⓘ)を開き、マイクの設定を「許可」に変更してページを
  再読み込みする。
- **デバイスが他アプリで使用中と出る** → RME TotalMixや他のブラウザタブ、
  他のビデオ会議アプリなどFirefaceを掴んでいるものを閉じる。
- それでも直らない場合は診断ログの内容をそのまま伝えてください。

## エフェクト一覧

- **タイムマシン・ルーパー** — 数秒〜30秒前の演奏を呼び戻すディレイ。
  フリーズで無限ループ、ジャンプボタンでランダムな時間に飛ぶ。Timeは
  常に固定(下記参照)、Feedbackだけランダム対応。
- **空間ディレイ・バンク**(4トラック) — 各トラックが「直近の数秒〜
  十数秒」を独立して常時サンプリングし続け、その場でループ再生する
  Electro-Harmonix 16 Second Digital Delay系の発展形。
  - **Loop長**: そのトラックがどれだけの長さを繰り返すか。トラックご
    とに異なる長さがデフォルトで設定済み。**このパラメータは常に固定
    (ランダム化しない)**。スライダーを動かすと次の瞬間に新しい区間を
    録り直す(クロスフェード付きの一発切り替えで、なめらかなランプでは
    ないのでピッチが揺れない)。
  - **Rate**: 倍速・ピッチを一体で変える、テープ的な速度ノブ。1.0xが
    「揺れゼロ」の基準値。ここだけランダムウォーク対応。
  - **逆再生**: ボタンで手動切り替え、または「逆再生もランダムに混ぜる」
    を有効にすると再サンプリングのたびにランダムで順再生/逆再生を選ぶ。
  - **🔄**: 今すぐ新しい区間を録り直す(手動リサンプル)。
  - **レーダー**: 円形パッドをドラッグしてトラックの空間位置(左右パン
    + 奥行き。奥に行くほど小さく暗く)を設定。「位置R」を有効にすると
    その場所がゆっくりランダムに動き続ける。
  - 自動的にも4〜20秒ごとにトラックごとバラバラのタイミングで再サンプ
    リングが走り、内容が少しずつ入れ替わっていく。
- **GRMディレイ** — Attack(反復音の立ち上がり速度)とSustain(尾の長さ)
  で反復のエンベロープを彫刻するディレイ。
- **ランダムスイッチ** — 不規則な間隔で信号を断片化するカオス・ゲート。
- **ドリフト・ビブラート** — ピッチのビブラートのレートと深さが演奏中に
  じわじわ動き続ける。

### なぜディレイのTime/Loop長はランダム化しないのか

DelayNodeのdelayTimeをなめらかにランダムウォークさせると、再生位置が
連続的にずれていくため実質的にワウ/ピッチベンドがかかったように聞こえ
ます(EHXの実機が時間ノブを動かすとピッチが動くのと同じ原理)。最初は
それを「味」として実装していましたが、狙って鳴らしたいピッチ/速度の
変化はRateノブという専用パラメータに切り出し、Time/Loop長は常に固定に
しました。空間ディレイ・バンクのLoop長を変えても、それは「次に録り直す
区間の長さ」が変わるだけで、今鳴っている音がなめらかに歪むことはあり
ません。

すべて内部はWeb Audio API(空間ディレイ・バンクはAudioWorklet)のみで
完結しており、外部ライブラリへの依存はありません。
