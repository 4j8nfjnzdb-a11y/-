Phosphor Cut — ブラウン管ビデオフィードバックのライブ・コラージュ卓

使い方
  index.html をブラウザ（Chrome / Safari / Edge の最新版）で開くだけで動きます。
  インストールやサーバーは不要です。素材はブラウザの中だけで処理され、外には送られません。

中身
  index.html   そのまま開ける単体版
  app.html     Claude のアーティファクト用（本文のみ）
  src/         元のソース（page.html / remux.js / app.js）
  build.sh     src から app.html と index.html を作り直すスクリプト（sh build.sh）

メモ
  - 単体版ではカメラボタンも使えます（ブラウザの許可が必要）。
  - 録画・書き出しは「ファイルに保存」でダウンロードされます。
  - フォントは Google Fonts から読み込みます。オフラインでは代わりのフォントで表示されます。
