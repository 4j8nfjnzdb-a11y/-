対応フォーマットについて
MOV（iPhone・カメラ）H.264 は Chrome・Safari・Edge で読めます。HEVC（H.265）は Safari と、ハードウェアデコードが効く Chrome / Edge で読めます。ProRes は Mac の Safari だけです。
M2TS / MTS / TSAVCHD・Blu-ray 系の H.264 と HEVC を、再エンコードせずにブラウザ内で MP4 に詰め替えます。AAC 音声はそのまま、AC-3 音声は Safari で鳴ります。鳴らない環境では映像だけで読み込みます。MPEG-2（HDV）は扱えません。
MP4 / M4V / WebM / MKVブラウザが再生できるコーデックならそのまま使えます。
画像JPEG / PNG / WebP / GIF。HEIC は Safari で読めます。
書き出しChrome・Safari は MP4、それ以外は WebM で、画面の 960×720（4:3）を実時間で録画します。
