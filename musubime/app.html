M-VAVE FM-1 用に書いた C のファームウェアを、そのまま WebAssembly にして動かしています。画面も同じ C が描いています。6 つは別々のファームウェアで、切り替えると前の音は残りません。

どのプロジェクトでも

  • EDIT を押している間は音源ページ。SELECT でスロット 1〜4、ALGO で音源、PRESET 音程（1/12 オクターブずつ）、K1 明るさ、K2 減衰の倍率、K3 音量、K4 フィードバック。音源は FM の 28 種類: KICK SNARE HAT OHAT TOM RIM COWBEL CYMBAL / SINE EPIANO BELL MARIMB BASS BRASS ORGAN PAD PLUCK REED STRING / METAL GLASS WIND CHAOS DRONE VOX DIGI ZAP / SYNTH。
  • 1 つだけでも選べる。スロット 2〜4 を空（−）にすると、そのプロジェクトの音は全部スロット 1 の音源で鳴る。スロット 1 も空なら、各プロジェクト自前の FM の音。使い方は、変化 = トラック 1〜4、フェルドマン = 層 A〜C、PMVRS = P・M・V・R、線 = 一音ずつ（どのスロットかも「一周に一か所」の変化の対象）、崩し = VOICE ページの SOURCE を SLOTS にして打ち直しごとに順番、適応 = 自分で鳴らす声（構造が一歩変わるたびに次のスロットへ）。
  • REC 手の動き（つまみ・鍵・ボタン）を録る → もう一度押すとそのままループ再生 → もう一度で停止。1 秒長押しで消去。ループの上から手で重ねて動かせる。
  • HOME 0.7 秒長押しで、そのプロジェクトのいちばん単純な状態へ戻す。
  • PLAY 音の on / off（系は動き続ける）。
  • 出口には必ず DC カット、急な音量の跳ね上がりを抑えるガード（最大 -9 dB を 0.3 秒で戻す）、-3 dBFS のリミッターが入る。NaN や無限大は無音にして画面の右上に NAN と回数を出す。
  • 画面右下の SPD / REV / STILL / E は、つまみの速さ・向きを変えた回数・静止時間・手の運動量。
