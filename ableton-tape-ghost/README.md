# Tape Ghost — Ableton Live用 Max for Liveエフェクター（2パターン）

要望内容（ずっと裏で録音し続け、ミックスを上げると過去の音が出てくる／巻き戻し／ジャンプ／
微分音を含むピッチ変更／2クリックのループ＋ループ位置シフト／ランダムなカットアップ
「ミラクル」ボタン）を実装した Max for Live オーディオエフェクトです。

**重要な前提**：このセッションには Ableton Live / Max がインストールされておらず、実機での
動作確認ができていません。パッチは Max for Live の標準的なテクニック（`record~ @loop 1` +
`phasor~` による書き込み位置トレース、`wave~` によるスクラッチ読み出し、`pitchshift~` に
よるピッチシフト、`value` オブジェクトによる状態保持）だけで組んでいますが、Max を開いて
実際に音を出してみるまでは「一発で完璧に動く」とは言い切れません。Max はパッチを開くと
コンソールにエラー/警告を出すので、もし変な挙動があれば下の「トラブルシューティング」を
見ながら Max の編集画面（デバイスを右クリック→「Edit」）で配線を直接確認・修正できます
（Max はビジュアルなので、テキストのバグ報告より原因が分かりやすいはずです）。

## ファイル

- `TapeGhost_A_FullControl.amxd` — フル操作版（Jump, Rewind, Loop, Loop Shift, Miracle, Pitch, Mix）
- `TapeGhost_B_MiracleFocus.amxd` — 軽量版（Jump/Loop Shiftを省略し、代わりに Freeze ボタンを追加。
  よりパフォーマンス寄り、崩れ・グリッチ重視）

## 使い方（共通）

1. Ableton Live のオーディオトラック（ボーカルをLINE入力しているトラックなど）の
   エフェクトチェーンに `.amxd` をドラッグ＆ドロップ。
2. 何もしなくても裏では常時、直近10分間をループ録音し続けています（無音・無反応）。
3. **Mix** フェーダーを上げると、原音が引っ込み、代わりに「過去の音」が鳴り始めます。
   何もボタンを押していない状態では、デフォルトで「2秒前」を再生する短いディレイのような
   挙動になります（Rewind / Loop / Miracle のいずれかを使うとそちらが優先されます）。

## コントロール

### A: TapeGhost_A_FullControl

| コントロール | 説明 |
|---|---|
| Mix | 原音 (0) ⇔ 過去の音 (1) のクロスフェード |
| Jump | 0〜120秒前へジャンプ（グライドあり） |
| Rewind (トグル) | ONの間、連続的にどんどん過去へ巻き戻る（テープ逆回転風） |
| Rewind Speed | 巻き戻る速さ（0.1x〜6x） |
| Pitch | -24〜+24半音。小数値＝微分音（例: 3.5 = 3半音+50セント） |
| Loop Mark（ボタン） | 1回目クリック＝ループ開始点を記録／2回目クリック＝終了点を記録してループ開始／3回目クリックでループ解除 |
| Loop Shift（ボタン） | 今のループ範囲を「Loop Shift Amount」秒ぶん、さらに過去へずらして再ループ |
| Loop Shift Amount | シフト量（秒） |
| Miracle（トグル） | ONの間、過去の録音からランダムな短い断片（0.5〜3秒程度）を切り出して
  ランダムな間隔で次々に再生し続ける「カットアップ」モード |
| Miracle History Window | どこまで過去から断片を拾うか（秒） |
| Miracle Density | 高いほど断片が短く・切り替えが速く／低いほど断片が長め |

Loop / Miracle 中も Pitch フェーダーはそのまま効きます（別系統の `pitchshift~` を通しているため）。

### B: TapeGhost_B_MiracleFocus

Aから Jump と Loop Shift を省略し、代わりに **Freeze**（ボタン）を追加：押した瞬間の
再生位置でごく短い「スタッター」ループを即座に作ります（Loop Mark の1回目+2回目を
一瞬でやるイメージ）。よりライブ演奏向けのシンプル版です。

## 仕組み（概要）

- 常時 `record~ tg_*_buf_L/R @loop 1` で入力を10分バッファへ円環的に録音。
- `phasor~`（周期600秒=バッファ長にジャストで同期）が「今どこを書き込んでいるか」を
  0〜1の位相として常時出力（`record~` の "record" メッセージと同時にphaseを0へリセットして
  同期させています）。
- 読み出しは `wave~`（MSP標準のスクラッチ用オブジェクト）に0〜1の位相信号を渡す方式。
  Jump/Rewindはこの位相をずらす信号、Loop/Miracleは専用の `phasor~` で
  start〜end間を繰り返す信号を作り、`line~` でクロスフェードして `wave~` に渡しています。
- ピッチは読み出し後に `pitchshift~` で独立制御（時間軸のスクラッチ速度とは別系統）。

## トラブルシューティング / 実機で試すときの注意

- **音が出ない場合**：Ableton下部のMax windowを開いてエラーが出ていないか確認してください。
  特に `pitchshift~` はMaxのバージョンによって挙動・引数の受け方が異なる場合があります。
  もし音が通らない場合は、デバイスを Edit で開き、`pitchshift~` を一旦 `thru~` や
  `[* 1.]` に差し替えて、ピッチシフト抜きで音が出るか切り分けてみてください。
- **CPU/メモリ**：10分×ステレオのバッファはメモリを数百MB使います。重い場合は
  `buffer~ tg_a_buf_L 1 600000` の `600000`（ミリ秒）を短くしてください（例: 120000 = 2分）。
  A/Bとも2箇所ずつ（buf_L, buf_R）あるので同じ値に揃えてください。
- **ループ/ミラクルの継ぎ目でプチノイズが鳴る**：これは仕様です（テープの誤動作／バグっぽい
  高揚感を狙った設計のため、あえてクロスフェードを最小限にしています）。気になる場合は
  Editモードで `loopactive_line` や `msg_active1`/`msg_active0` のグライド時間（15ms）を
  伸ばすと滑らかになります。
- **配線がおかしいと感じたら**：Max for Live はビジュアルパッチャーなので、デバイスを
  右クリック→Editで開けば全結線を目で追えます。オブジェクト名にコメントを添えてあるので
  （=== ... === という水色のコメント帯）、どの塊が「録音」「オフセット」「ループ」
  「ミラクル」「出力」なのか一目で分かるようにしています。

## カスタマイズの起点

- バッファ長（何分遡れるか）: `buffer~` と `record~` の引数、および `phasor~` の周波数
  （= 1/バッファ秒数）を合わせて変更。
- Miracleの断片の長さレンジ: `mir_len_expr` の `0.5+...*2.5` の部分。
- Rewindの最大速度レンジ: `RewindSpeed` パラメータの範囲（0.1〜6）。
