# Tape Ghost (Web版)

裏で常時録音し続け、Mixフェーダーを上げると原音の代わりに過去の音（巻き戻し／ジャンプ／
ループ／ランダムなカットアップ「Miracle」）が現れる、ブラウザだけで動くテープ・ゴースト・
エフェクターです。サーバーには一切音声を送信しません（すべてブラウザ内で処理）。

Ableton Live用のMax for Liveデバイスとして最初に作りましたが、実機で検証できない環境
だったため、代わりに実際にこの場でテスト済みのWeb Audio版に切り替えました。

## 使い方

1. `index.html` をダブルクリックしてブラウザで開く（Chrome/Edge/Firefox推奨）。
2. バッファ長（何分遡れるか）を選んで「マイク/ライン入力を開始」。マイクの使用許可を
   ブラウザが聞いてくるので許可してください。
3. 上部のタブで「Full Control」（フル操作版）と「Miracle Focus」（Freezeボタン付きの
   軽量版）を切り替えられます。
4. Mixフェーダーを上げると、原音の代わりに「2秒前」がデフォルトで鳴り始めます。あとは
   Jump / Rewind / Loop Mark（2クリック）/ Loop Shift / Miracle を自由に操作してください。
5. 「入力を停止」でマイクを解放して終了します。

## 実装・検証について

- 循環バッファへの録音・可変速スクラッチ読み出し・微分音まで含むピッチシフト（グラニュラー
  方式）は、このセッション内でNode.jsを使って単体テスト＋実際のChromiumブラウザでの
  動作確認（マイクの代わりに合成トーン入力を使用）まで行っています。
  - 遅延読み出しが原音を正確に再現すること
  - 逆再生（Rewind）が時間を遡って読むこと
  - ループが完全に周期的に繰り返すこと（実装していたピッチシフターのわずかなドリフト
    バグもこの過程で発見・修正済み）
  - ピッチシフトが指定した半音どおりに周波数を変えること
  - Jump / Miracle / Freeze が指定した「何秒前」を正しく再生すること
  などを実際に確認しています。ゼロから作った実験的なエフェクトとしては、かなり
  作り込んで検証したつもりです。
- 音声処理は本来 AudioWorklet（低遅延・別スレッド）で行いますが、`index.html` を
  ローカルファイルとして直接ダブルクリックで開いた場合、ブラウザの仕様で
  AudioWorkletの読み込みがブロックされることがあります。その場合は自動的に
  ScriptProcessorNode（やや古い方式、若干レイテンシーが増えます）にフォールバック
  するようにしてあり、これもブラウザで動作確認済みです。

## 制限・注意点

- ピッチシフターは軽量なグラニュラー方式（遅延ラインの2タップ・クロスフェード）のため、
  大きく上下させるとやや粒っぽい（ローファイな）音になります。これは仕様です
  （むしろ「バグっぽい高揚感」に合うかと思います）。
- バッファ長を長く（10分など）すると、ブラウザのメモリ使用量が増えます（ステレオ10分で
  概算 数百MB）。重く感じたら短めの設定（1〜3分）にしてください。
- マイク入力はブラウザの機能のみで完結しており、録音データはどこにも保存・送信されません
  （タブを閉じれば消えます）。

## ファイル構成（開発者向け）

- `index.html` — 配布用の単一ファイル（これだけで動きます）
- `dsp-core.js` / `worklet-processor.js` — 実際に動いているDSPのソース（読みやすさのため
  分割していますが、`build.js` が index.html に埋め込みます）
- `app.js` — UI・マイク接続・AudioWorklet/フォールバックの制御
- `test-dsp.js` / `test-engine.js` — Node上でのDSP単体テスト
- `browser-test.js` — Playwrightによる実ブラウザでの結合テスト
