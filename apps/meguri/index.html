入力を絶えずリングバッファへ録りため、そこから短い窓を切り出してループさせるサンプリング＋ミキサー。 入力を接続すると4つのレイヤーは自動的に流れ始め、窓の長さ・パン・奥行きはそれぞれ自分の速度でゆっくり揺れます。 レイヤーごとに "flow（ランダムに流れる）" と "固定（止める）" を切り替えられます。

プレビューについて。 ここは Claude のサンドボックス内プレビューです。 ブラウザやシステムの設定によってはマイク許可がそもそも要求されない場合があります。 RME Fireface のような外部インターフェースを本格的に使う場合は、コード一式を GitHub のブランチ から取得し、手元で python3 -m http.server などで開くと確実に動作します。

1. 入力 / 内蔵録音

RME Fireface を使う場合は OS 側の入力デバイスとして Fireface を選び、TotalMix FX で聴きたいチャンネルを ブラウザに見えているステレオペア（通常 1/2）にルーティングしてください。ブラウザの自動エコー除去・自動ゲインは 無効化して接続します。「入力を接続」を押すと一度だけ許可ダイアログが出て、そのあと入力欄に実際のデバイス名 （内蔵マイク／Fireface など）が表示されます。選び直すと自動的に接続し直します。
