RPS / 04CH
LIVE INPUT 未接続(各chはデモ音源で試せます)

① サンプルを読み込む(未読込ならデモ音源) → ② PLAYでフレーズを確認 → ③ フェーダーを上げてLOOPを押すとフレーズ内のランダムな区間が粒状に鳴り続ける → ④ EVOLVEのままだと区間が揺れ動き続け、押すとFIXEDでその場に固定、NEWで手動で区間を作り直せる → ⑤ RND PITCHでピッチもランダムに揺らせる。仕上がりはMASTERのRECで録音してSAVE。
