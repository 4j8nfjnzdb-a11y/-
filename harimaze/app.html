貼交屏風（はりまぜびょうぶ）は、絵や書や版画の断片を一双の屏風に貼り合わせたもの。ひとつずつは別の場所から来た紙なのに、並べると一枚の景色になります。

ここでは、3XL や West Mineral のまわりで鳴っている「アンビエントとクラブの間」の音、Ulla や Pontiac Streator、Huerco S. たちを入口に、その手前にいる先行世代（Oval、刀根康尚、竹村延和、Jan Jelinek、Philip Jeck…）と、日記や声や場所を素材にする周縁の作家までを、インタビューとレビューから読み解きます。

各項目には出典を付けています。本人の発言は出典の文脈を要約したもので、直接の引用は原文のまま示しました。機材について本人の一次資料が見つからなかった作家は、そう書いています。

    max/msp
    
        
    Max パッチ
    
        
    5 本とも gen~ のコードボックス 1 つが心臓部です。音源・パラメータ・プリセット・出力（音量・録音・位置と状態のモニター）だけのシンプルな構成で、in1 に信号を入れると外からイベントを起こせます。
    
      
    
      
    
        
        .maxpat ×5、GenExpr ソース、説明書（README）が入っています。Max 8.1 以降 / Max 9。
      
    
      
    
      
    
        
    パッチのつくり
    

    [r tenki_speed] → [flonum] → [prepend speed] → [gen~]     各パラメータ。受信名があるのでプリセットで数字も動く
[●] → [; tenki_speed 1; tenki_size 0.25 …(               プリセット（隠しメッセージ）。起動時は 1 番目が入る
[button] → [click~] → gen~ in1                            今すぐイベント。外部の信号や他のマシンでも駆動できる
gen~ out1 out2 → [*~] → ezdac~ / meter~ / sfrecord~       出力・メーター・録音
gen~ out3 → [snapshot~] → slider                          再生位置（戻る・進むが見える）
gen~ out4 → [snapshot~] → 数字                             状態（天気、故障の種類、morph など）
    
        
    バッファ名と受信名はマシンごとに別なので、5 本を同時に開いて重ねられます。例えば kizu の out4 を tenki の in1 に入れると、CD が飛ぶたびにループの天気が変わります。
    
        
    検証: GenExpr は JavaScript に変換してオフラインで試験しています（数値が壊れない、音量が暴れない、各イベントが起きる、クリックしない、など）。Max 本体で開いての確認はまだです。エラーが出たらコンソールの文面を送ってください。
