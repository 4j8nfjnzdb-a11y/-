# 触り sawari

音を並べることと、空間を編集することを分けない音楽制作環境。ブラウザ（Mac の Chrome / Safari）で動きます。

- 開き方：`index.html` をブラウザで開く（ビルド済み・外部依存なし。フォントだけ Google Fonts から）。
- ビルド：`./build.sh`（`src/` を `app.html` と `index.html` にまとめる）
- テスト：`node tools/test.js`（シミュレーションと入出力の単体テスト）、
  `NODE_PATH=$(npm root -g) node tools/e2e.mjs` と `tools/e2e-more.mjs`（Chromium で実際に音を鳴らす通しテスト）

名前の「さわり」は、触れることと、三味線の「さわり」（弦にわざと雑音を混ぜる仕組み）の両方から。

---

## 1. 設計思想

**視覚的に操作できることと、視覚的に理解できることは同じではない。** この前提から設計しています。

1. **翻訳規則を押し付けない。** 画面上の形は音から決まりません（音の波形から形を作らない）。断片の「姿」は偶然に与えられ、自由に変えられます。空間と音を結ぶのは「法則」という表だけで、表は書き換えられ、空にもできます。
2. **空間が時間になる。ただし一通りではない。** 波紋は「距離」を、回る針は「角度」を、列車は「線路上の順序」を、走査線は「横の位置」を時間にします。拍に合わせるもの（同期）と秒で動くもの（非同期）が同じ世界に並びます。いわゆるタイムライン（走査線）も、世界の中の一つの物にすぎません。
3. **規則と偶然を同じ場所に置く。** 群れは自分で飛び、断片は鳴るたびに少しずつ変わり（変わりやすさ）、確率で鳴らないこともあります。偶然はすべて「種」から生まれるので、同じ種なら同じ展開を書き出せます。
4. **ずれを許す。** 見た目だけ動いて音には伝わらない動き、音だけが遅れる「ずれ」、画面全体を音より遅らせる「見た目の遅れ」、鳴らなかった出来事も見た目には現れる、など。
5. **操作が先、理解は後。** 法則の表は見えますが、断片の上には何も説明が出ません。動かしてみて初めて関係が分かることを前提にしています。

## 2. 画面構成

画面全体が制作空間（俯瞰した一枚の敷地）。その上に製図用紙のような板が浮かんでいます。

| 位置 | 役割 |
|---|---|
| 全面 | 世界。断片・物・線路・列車・波紋・針・走査線・群れ・部屋・糸 |
| 上 | 再生／一時停止・最初へ・時刻・拍（BPM）・種・法則・素材・取り消し・録音・書き出し・保存・開く |
| 左 | 道具（選・触・線・車・波・掃・群・室・糸・物・手） |

| 呼び出し | 法則の表（L）、素材の棚（M）、使い方（?） |

## 3. 操作体系

### 世界にあるもの

| もの | 何をするか |
|---|---|
| **断片** | 音声の一部分。それ自体は鳴らない。鳴り方は 打（触れられると一度）／環（ずっと鳴る。触れられると頭に戻る）／帯（通ったものの位置を読む。向きで順再生・逆再生が決まる） |
| **列車**（線路の上） | 線路の近くの断片を通りがかりに鳴らす。車両の数だけ繰り返す。環状線は反復、開いた線路は折り返し |
| **波紋** | 一定の周期で輪を放ち、輪が届いた断片を鳴らす（距離＝時間） |
| **掃引**（回る針） | 針が通過した断片を鳴らす（角度＝時間、円＝反復） |
| **走査**（直線） | 左から右へ動く線（横位置＝時間） |
| **群れ** | 迷う／群がる／訪ねる。入った断片を鳴らし、帯の断片では読む。拍に寄せることも、自由にもできる |
| **部屋** | 中にある断片の音に加工を掛ける（フィルター・歪み・反響・残響・砕き・揺れ・輪変調・刻み を任意の順に連ねる）。壁を閉じると群れを閉じ込める |
| **糸** | 前の断片が鳴ると、糸の長さ ÷ 伝わる速さ（または拍）だけ遅れて後ろが鳴る。確率つき。輪にすると自走する反復になる |
| **物** | 音を持たない物体。まわりの断片の「近さ」「混み」を変える（見た目の物が、間接的に音を変える） |

### 法則（対応関係を自由に割り当てる表）

行が空間の性質 14 種、列が音の性質 16 種。升目の強さ（−1〜+1）で「その性質が増えるとその音をどれだけ動かすか」を決めます。一つの性質から何本でも引けるので、同じ操作が複数の音楽的な結果を持ちます。

- 空間：横・縦・大きさ・向き・形・高さ・近さ・混み・中心・奥（部屋の）・動き・勢い・揺らぎ（見えない波）・偶然
- 音：音量・速さ（テープ式）・音程（長さ保持）・伸縮（高さ保持）・定位・音色・頭・長さ・粒・散・逆・歪・遠（ディレイ）・響（残響）・確率・ずれ

法則は 甲・乙・丙 の 3 組。断片ごとにどれに従うか（または「無」）を選べるので、同じ形の断片が違う法則で鳴ります。「振る」でまばらな法則をランダムに作れます。

### 道具と鍵盤

| 鍵 | 道具・操作 |
|---|---|
| V | 選ぶ・動かす（Alt+ドラッグで複製、丸い取っ手で回転、四角で大きさ） |
| F | 触れて鳴らす（なぞって次々。帯の断片はなぞった位置と向きで読む） |
| R / T | 線路（ドラッグ＝自由線、クリック＝点、Shift＝円）／列車 |
| P / S / D | 波紋／針（クリック）・走査線（ドラッグ）／群れ |
| B / W / O / H | 部屋／糸／物／見る場所を動かす |
| Space | 再生・一時停止（押したままドラッグで画面移動） |
| ⌘Z ⇧⌘Z ⌘D ⌘G ⌘A ⌘S ⌘O | 取り消し・やり直し・複製・まとめる・全選択・保存・開く |
| 1〜6 / Shift+1〜6 | 場面を呼び出す／残す |
| L / M / Tab / 0 / ? | 法則／素材／UI を隠す／全体表示／使い方 |

### 音声編集

ファイルを落とす（WAV / AIFF / AIFC / MP3 / M4A など）→ 断片になる。性質の板の波形で：

- ドラッグで範囲を選ぶ → 「範囲を残す」（トリミング）、「切り出す」（新しい断片）
- クリックで位置 → 「ここで切る」、「N 等分」、「切れ目で刻む」（立ち上がり検出）
- 素材の棚から「刻んで撒く」（ファイル全体を刻んで周囲に散らす）
- 音量・速さ・音程・伸縮・定位・音色・頭・長さ・逆再生・フェードイン／アウト・粒・散・歪・遠・響・確率・ずれ
- 複数選択して 円に／列に／散らす／入れ替える（ランダムな再配置）／揺さぶる／まとめる／糸で順につなぐ

### 時間の保存と書き出し

- **保存**：ZIP（`sawari.json` と元の音声ファイル）。場面も入る。作業はこのブラウザの IndexedDB にも自動保存。
- **書き出し**：世界を最初から種どおりに鳴らした WAV（24 bit）。同じ種なら毎回同じ音（テストで確認）。結果を素材として取り込み直せる。
- **録音**：いま鳴っている音（触れた操作を含む）をそのまま WAV に。

## 4. 技術構成

依存ライブラリなしの JavaScript、一枚の HTML。

| 層 | ファイル | 中身 |
|---|---|---|
| 核 | `src/core.js` | 種つき乱数、ノイズ、線路の幾何 |
| 入出力 | `src/codec.js` | AIFF/AIFC・WAV の読み込み（Chrome は AIFF を自前で読めないため）、WAV 書き出し、ZIP、立ち上がり検出、ゼロ交差 |
| 世界 | `src/world.js` | 保存される設計データと、空間を時間に変えるシミュレーション（10 ms 刻み。通過時刻は解析的に求めて刻みより細かい精度で出す） |
| 音 | `src/audio.js` | Web Audio の標準ノードだけで鳴らすエンジン。打＝バッファ再生、環＝ネイティブループ（ゼロ交差に合わせ、速さはなめらかに変化）＋粒の層、音程・伸縮・粒＝自前のグラニュラー、部屋＝エフェクトの連鎖、世界のディレイと残響、リミッター |
| 描画 | `src/draw.js` | Canvas 2D。地面に斜めの視点（俯瞰の角度は見た目だけ）。平らな記号・立体の建物・線路・列車・輪・鳥を一つの奥行き順で描く |
| 画面 | `src/app.js` `src/panels.js` `src/input.js` | 状態・履歴・保存・再生・書き出し・録音／性質の板・法則の表・素材・場面／道具・入力・描画ループ |

**安定性のための設計**

- 時計は二つに分けています。シミュレーションは音の時計（`AudioContext.currentTime`）より 0.1 秒先まで進み、出来事を正確な時刻で予約します。画面は自分の時刻（音と同じか、わざと遅らせた時刻）で同じ世界を描きます。
- タブが眠っていたときは、溜まった出来事を一度に鳴らさず、世界の時間を待たせます。
- 同時発音を 90 声までに抑え、停止時は予約済みの音も含めて止めます。
- AudioWorklet は録音にだけ使い（使えなければ ScriptProcessor）、音の生成は標準ノードに任せています。Safari でも同じ経路で動きます。
- 書き出しは同じシミュレーションとエンジンを `OfflineAudioContext` で走らせます（1 秒ごとに suspend して少しずつ予約）。

## 5. 段階と現状

| 段階 | 内容 | 状態 |
|---|---|---|
| 1 | 読み込み・複数音声・分割・配置・移動・複製・同時再生・視覚操作の反映 | 実装・テスト済み |
| 2 | 相互作用（糸・近さ・混み・部屋）、空間的再生（列車・波紋・針・走査・群れ）、加工、偶然と自律（群れ・確率・変異・種）、視覚表現 | 実装・テスト済み |
| 3 | 保存／読み込み、WAV 書き出し、録音、履歴、場面、法則の自由な割り当て、負荷対策 | 実装・テスト済み |

**まだ足りないところ**

- 音程と伸縮は粒（グラニュラー）による処理で、フェーズボコーダほど滑らかではありません。
- 法則は世界に 3 組。断片ごとに独自の表を持つことはまだできません。
- 視点は斜め上からの一方向だけで、カメラを回せません（Three.js を使う 3D は、今の負荷と操作の単純さを優先して見送り）。
- 場面と場面の間を自動で移ろう機能、MIDI や外部機器との同期はありません。
- 数百を超える断片や長大なファイル（数十分）は試していません。読み込んだ音はメモリ上に元・逆再生用・モノラルの 3 通りを持ちます。
