# 粉砕 / FUNSAI

ビートを刻んで、凍らせて、変拍子で踏み潰すためのブラウザ装置。
ブレイクコア／ジャングル／ドリルンベース系の「頭おかしいビート」を、
パッドを**押している間だけ**かかるリアルタイム処理で作る。

ビルド不要。`funsai/index.html` を開くだけ。

---

## 二つのモード

| | |
|---|---|
| **一本 / MONO** | ブレイク1本を16または32切片にスライスして並べ替える。アーメン的なチョップはここ。 |
| **四本 / KIT** | バス／ハット／スネア／シンバルの4トラック。**トラックごとに**別々のエフェクトをかけられる。 |

KIT モードではトラックごとに**歩数**（4〜32）と**分解能**（½〜×4）を変えられる。
BD を7歩、SD を5歩にすればポリメーターになり、勝手にずれ続ける。

## 16個の XY パッド

押した**位置がそのままパラメータ**になる。横軸＝X、縦軸＝Y。
押しながら指を動かすと値が連続で変わる。複数同時押しで重なる。

| | | | |
|---|---|---|---|
| **刻 STUT** 分割 / 巻戻 | **連 ROLL** 初速 / 加速 | **凍 FRZ** 粒 / 音程 | **逆 REV** 分割 / 速度 |
| **階 STAIR** 音程幅 / 段数 | **変 ODD** 拍子 / 揺れ | **散 SCRM** 粒度 / 範囲 | **混 CHAOS** 確率 / 粒度 |
| **停 STOP** 時間 / 底 | **断 GATE** 速度 / 開度 | **砕 CRSH** 間引 / ビット | **環 RING** 周波数 / 掃引 |
| **濾 FILT** 開き / 共鳴 | **遅 DLY** 時間 / 帰還 | **滲 SMEAR** 粒長 / 拡散 | **壊 DSTR** 歪 / 雑音 |

- **刻/連/凍/逆/変/散/混** はリングバッファを掴んで鳴らし直す系。直前の1小節分を捕まえて、
  拍グリッドにスナップしてループする（＝ビートリピート）。分割は 1/2 から 1/128 まで。
- **階・停** は単独でも効くが、他の捕獲系と**重ねて**使うのが本領。
  `凍 + 階` で音程が階段状に上がっていく凍結、`刻 + 逆` で逆回転スタッター、
  `変 + 混` で拍子も音程も崩壊する。
- **断/砕/環/濾/遅/滲/壊** は通過した音をそのまま加工する。捕獲系と自由に併用できる。

### 操作

- **保持 LATCH** — パッドが押しっぱなしになる。別のトラックに切り替えても鳴り続ける。
- **XY記憶** — 押した位置ではなく前回の値から始め、指の移動量で調整する。
- **自動破壊** — アプリが勝手にパッドを叩き始める。右のスライダーが激しさ。
- **鍵盤** — `1234 / qwer / asdf / zxcv` が16パッド（押しっぱなし）、`space` 再生、`0` 全解除。
- **賽** — MONO は切片の並びを、KIT は格子と歩数をランダムに組み直す。

### 送り先 / TARGET

パッドをどのバスにかけるかを選ぶ。KIT では `総 MST` に加えて `BD / HH / SD / CY` を個別に選べる。
バス名の下に青い線が出ているときは、そのバスで何か（自動破壊を含む）が動いている。

## 音源

ドラムは全部コードで合成しているので音声ファイルは同梱していない。

- 鋼 HAGANE（909系） / 土 TSUCHI（808系） / 肉 NIKU（生ドラム寄り） / 鉄 TETSU（ガバ・工業） / 電 DEN（デジタル・グリッチ）
- 型：AMEN, THINK, APACHE, FUNKY, GABBER, FOOTWORK, BLAST, DRILL, HALFTIME, JUNGLE

**読込** から自分のファイルも入れられる。MONO では尺を1小節に合わせて切片に割り、
KIT では選択中のトラックのワンショットになる。

## 録音

**●録音** で出力をそのまま録る。止めると `webm`（環境により `m4a`）で落ちてくる。

## 動かす

```sh
# そのまま開く場合
open funsai/index.html

# ローカルサーバー経由
npx http-server -p 8080 .
# → http://localhost:8080/funsai/
```

AudioWorklet のコードは `engine.js` の中に普通の関数として書かれていて、
`app.js` がそれを文字列化して Blob URL から読み込む。
そのためビルドも `addModule` 用の別ファイル配信も要らず、`file://` でも動く。

## 中身

| ファイル | 役割 |
|---|---|
| `engine.js` | AudioWorklet プロセッサ。シーケンサ、ボイス、キャプチャリング、16種のエフェクト。全部サンプル単位。 |
| `kits.js` | ドラム合成、パターン定義、ブレイクのレンダリング（メインスレッド）。 |
| `app.js` | 画面・状態・入力。 |
| `style.css` | 見た目。 |

エフェクトが「直前の音を掴み直す」方式なので、スタッターもフリーズも
サンプル単位で正確に拍に乗る。ノードグラフでは出せない挙動をここで作っている。
