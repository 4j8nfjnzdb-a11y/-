# 粉砕 / FUNSAI

ビートを刻んで、凍らせて、変拍子で踏み潰すためのブラウザ装置。
ブレイクコア／ジャングル／ドリルンベース系の「頭おかしいビート」を、
パッドを**押している間だけ**かかるリアルタイム処理と、
**一打ごとに書き直すシーケンサ**で作る。

ビルド不要。`funsai/index.html` を開くだけ。

---

## 素材：四人のドラマーを同時に叩かせる

**4レーン**あり、それぞれ独立した音源・役割・歩数・エフェクトバスを持つ。

**層 LAYERS** プリセットの初期状態:

| 層 | 音源 | 役割 | 効果 |
|---|---|---|---|
| 1 | AMEN | 低 | 胴と足だけ残る |
| 2 | FUNKY | 高 | ハットとシンバルだけ残る |
| 3 | THINK | 中 | 中域 |
| 4 | 和音 CHORD | 全・**残** | 爆速ビートの上で鳴る遅い和声 |

**役割**は帯域を切り分ける。低は 260Hz 以下、高は 1.6kHz 以上。
計測すると、低のレーンはキックを 0.176 残してハットを 0.0001 まで落とし、
高はその逆になる。一本に聞こえるが、実際は三人が別々に叩いている。

層4の **残** は「無音ドロップの間も鳴り続ける」指定。
全部が一瞬落ちて和音だけが残り、また爆発する、という構成がこれで出る。

**ドラム以外も刻める。** 弦・和音・声・電子・金属の5種を内蔵。
どれも小節の中で和音や母音や音域が変わっていくので、
32分に刻むと切片ごとに別の音になり、そのまま打楽器として使える。
**読込**から自分のファイル（ゲーム音・台詞・なんでも）も入る。

## 並べ方：同じ小節が二度と来ない

**書換 REWRITE** を入れると、小節をコピペせず、一打ごとに
「次に何を鳴らすか」を鳴る直前に決め直す。

小節どうしの波形包絡を比べると:

| | 隣り合う小節の相関 |
|---|---|
| 書換 OFF | **0.99**（完全に同じ小節の繰り返し） |
| 書換 ON | **0.35**（毎回違う） |

書き換えの対象は個別に切れる ―
**切片 / 音程 / 逆 / 連打 / 加工 / 抜き / 拍子 / 倍速 / 無音**。
元のデータは書き換えないので、切ればいつでも書いた通りに戻る。

- **拍子** … 小節の切れ目で歩数を 3, 5, 7, 9, 11, 13 に差し替える。どこが頭か分からなくなる。
- **倍速** … 小節線で ×½ / ×1 / ×2 を行き来する。230の嵐から115の重いビートへ落ちてまた戻る。
- **無音** … 突然ぜんぶ落ちる。**残**を付けたレーンだけが残る。

手動でも **体感 半 / ×1 / 倍** で切り替えられる。

## 一打ごとの加工：追跡 TRACKER

**追跡**タブが本体。一行が一打で、数字を直接書く。
上下に擦ると値が変わり、叩くと切り替わる。

| 列 | 意味 |
|---|---|
| 切 | 切片番号（どのスライスを鳴らすか）／`··` は休符 |
| 音 | 半音単位のピッチ。同じスネアを上げ下げしてドラムでメロディを弾く |
| 逆 | 逆再生 |
| 連 | 連打数（1〜16）。一打を32分・64分で刻み直す |
| 速 | 連打の加減速。詰めると階段を転げ落ち、広げると開いていく |
| 加 | その一打だけの加工 … 砕（ビット）歪（歪み）濾（フィルタ）環（リング）停（テープ停止）飛（音飛び） |
| 量 | その強さ |

**連打が音程に変わるのは実測できる。** 連打数を上げていくと、
出力の周期性がそのまま繰り返し速度に一致する:

| 連 | 理論値 | 実測 |
|---|---|---|
| 4 | 46 Hz | 46 Hz |
| 6 | 70 Hz | 70 Hz |
| 8 | 93 Hz | 93 Hz |
| 12 | 139 Hz | 139 Hz |

スネアロールが音階みたいに聞こえるのはこれ。**速**（加減速）を付けると
周期が崩れて相関が 0.59→0.23 に落ちる ― 音程が溶ける。

**格子 GRID** は速記用。切片を持つレーンでは升目の色が切片番号を表すので、
そのままだと滑らかなグラデーション、散らすとノイズに見える。

## 16個の XY パッド

押した**位置がそのままパラメータ**。押している間だけ効く。複数同時押しで重なる。

| | | | |
|---|---|---|---|
| **刻 STUT** 分割/巻戻 | **連 ROLL** 初速/加速 | **凍 FRZ** 粒/音程 | **逆 REV** 分割/速度 |
| **階 STAIR** 音程幅/段数 | **変 ODD** 拍子/揺れ | **散 SCRM** 粒度/範囲 | **混 CHAOS** 確率/粒度 |
| **停 STOP** 時間/底 | **断 GATE** 速度/開度 | **砕 CRSH** 間引/ビット | **環 RING** 周波数/掃引 |
| **濾 FILT** 開き/共鳴 | **遅 DLY** 時間/帰還 | **滲 SMEAR** 粒長/拡散 | **壊 DSTR** 歪/雑音 |

捕獲系（刻連凍逆変散混）は直前の1切片を拍グリッドにスナップして掴み直す。
`凍+階` で音程が階段状に上がる凍結、`刻+逆` で逆回転スタッター。

### パッド右上の `R`

そのパッドを**乱数で振る**指定。押している間、ステップごとに X/Y が勝手に飛ぶ。
さらに **R を付けたパッドだけが自動破壊の抽選対象になる**
（どれにも付けなければ全部が対象）。「この3つだけ勝手に暴れてほしい」が作れる。

### その他

- **保持 LATCH** … 押しっぱなしにする。別のバスに切り替えても鳴り続ける。
- **XY記憶** … 押した位置ではなく前回の値から、指の移動量で調整。
- **鍵盤** … `1234 / qwer / asdf / zxcv`、`space` 再生、`0` 全解除。
- **賽** … 選択中のレーンの一打データ（切片・音程・連打・加工）をまとめて振り直す。

## 送り先 / TARGET

パッドをどのバスにかけるかを選ぶ。`総 MST` に加えて4レーンを個別に選べる。
バス名の下に青い線が出ているときは、そのバスで何かが動いている。

## 音源

ドラムは全部コードで合成しているので音声ファイルは同梱していない。

- 鋼 HAGANE（909系）/ 土 TSUCHI（808系）/ 肉 NIKU（生ドラム寄り）/ 鉄 TETSU（ガバ・工業）/ 電 DEN（デジタル・グリッチ）
- ブレイク: AMEN, THINK, APACHE, FUNKY, GABBER, FOOTWORK, BLAST, DRILL, HALFTIME, JUNGLE
- 素材: 弦 / 和音 / 声 / 電子 / 金属

### サンプルを入れたときの仕様

**読込ボタンは常に行き先を表示している**（`読込→層2` など）。入るのは
**選択中のレーン**＝格子で番号が黄色くなっているレーン。番号を叩けば選択が移る。

読み込むと長さから切片数を仮決めする:

| 長さ | 仮決め |
|---|---|
| 0.6秒以下 | **単発**（刻まない） |
| 0.6秒 〜 1.5小節 | **16切片** |
| 1.5小節より長い | **32切片** |

これはあくまで仮で、**切片**セレクタ（単発 / 4 / 8 / 16 / 32 / 64）で
読み直さずに割り直せる。割り直すと歩数が切片数に合わせられ、
追跡の「切」が `01,02,03…` の順に戻る（＝元のファイルがそのまま鳴る順）。
この並びを入れ替えるのがチョップ。

音源行の下に、いま何がどう鳴っているかが常に出ている:

```
層1 AMEN · 2.76秒 を 32切片（1切片 86ms） · 1歩 86ms ·
尺合わせON：切片を1歩に伸縮（1.00倍速＝0.0半音）
```

- **尺ON**（初期値）… 1切片を1歩ちょうどに伸縮する。
  ファイルのテンポとグリッドが違えばその分だけ音程が動くので、
  何倍速＝何半音ずれるかを上の行が数字で出す。
- **尺OFF** … 等倍。元の速さ・音程のまま鳴り、1歩で切られる。
- **単発** … 切片を使わず毎回先頭から等倍。音程は追跡の「音」列で変える。

読み込んだ音は BPM やドラム音源を変えても差し替わらない。

## 録音

**●録音** で出力をそのまま録る。止めると `webm`（環境により `m4a`）で落ちてくる。

## 動かす

```sh
open funsai/index.html          # そのまま開いてよい
npx http-server -p 8080 .       # サーバー経由でも
```

AudioWorklet のコードは `engine.js` に普通の関数として書かれていて、
`app.js` がそれを文字列化して Blob URL から読み込む。ビルドも別ファイル配信も要らない。
`file://` では Blob のオリジンが `null` になって `addModule()` に弾かれるので、
その場合だけ `data:` URL に落ちる（両方で起動を確認済み）。

## 中身

| ファイル | 役割 |
|---|---|
| `engine.js` | AudioWorklet プロセッサ。4レーンのシーケンサ、一打ごとのイベント、連打、書換エンジン、16種のバスエフェクト。全部サンプル単位。 |
| `kits.js` | ドラム合成、ブレイク、ドラム以外の素材生成（メインスレッド）。 |
| `app.js` | 画面・状態・入力。 |
| `style.css` | 見た目。 |

`engine.js` はただの関数なので、AudioWorklet のグローバルを差し替えれば
Node でそのままオフライン描画できる。上の実測値（連打の周期、小節相関、帯域分離）は
全部その方法でサンプル単位に測ったもの。
