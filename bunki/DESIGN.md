# bunki の設計と、その理由

## 1 ボイス

2 オペレータ(キャリアとモジュレータ)と、写像と、1 周期遅れのフィードバック。
6 オペは使い切らない:オペを増やして得られる複雑さは比率の積み重ね(禁止)か固定の音色で、
非線形性からは来ないから。

```
周期 k の頭(キャリア位相が一周した瞬間):
  F_i  = f_R(x_i)                         を公開(同じフレームで周期が終わるボイスは、先に全員公開)
  x_i  = F_i + ε (mean_j F_j − F_i)        大域結合。1 音なら x = F ちょうど
       + μ (s_(k−1) − s_(k−2))             both のみ:フィードバックの観測量が写像を押す
  d_k  = x_k − x_(k−1)
  I_k  = g · d_k   (lift sqrt: g · sign(d) √|d|)、音高ごとの上限つき
  β_k  = β0(u) + ν d_k                     both のみ:写像がフィードバック量を押す
  W_k(θ_j) = sin(θ_j + I(θ_j) sin(nθ_j) + β_k W_(k−1)(θ_j)),  j = 0..63
周期内の各サンプル:
  I(θ) = I_(k−1) → I_k を位相で直線補間(連続、周期は保たれる)
  y    = sin(θ + I(θ) sin(nθ) + β_k W_(k−1)(θ))      W は位相で線形補間
```

## 決めたことと、その理由

| 決めたこと | 理由 |
|---|---|
| インデックスは x ではなく差分 d | 1<R<3 の不動点 x* = 1 − 1/R は 0 でない。x をそのまま使うと純音にならない。差分が消すのは直流だけで、周期は保たれる |
| モジュレータを毎周期同期、比は整数 | 基本波形の周期が T0 でないと「周期 p = f0/p」が崩れ、写像と無関係な準周期(LCM の親戚)が混ざる |
| ノブは伸縮(u の整数ごとに倍化 1 段) | 周期 8 の帯は R 幅 0.004、周期 3 の窓は 0.013。線形ノブではカスケードがクリック数個に潰れる。節点はロジスティックの倍化点 r1..r6 |
| 整数演算、x は Q62 | カオスは 1 ulp の差を数十周期で広げるので、浮動小数では機種間で一致しない。30 bit では 89 反復で周期軌道に落ちた(R 3.95) |
| x を 0 と 1 から 2^−40 離す | 0 はどの R でも不動点。C の押しや 1 → 0 で落ちると、そのボイスは永久に純音になる |
| フィードバックは 1 周期遅れ、表は位相点で正確に評価 | DX7 型(1 サンプル遅れ)の不安定はサンプル周期の尺度で起き、f0 の周期倍を踏まない。表を「最後に書いたサンプル」で作ると、点ごとのサンプル数の揺れだけでノイズが出る(実装由来の複雑さ) |
| β0(u) を較正 | 1 周期遅れフィードバック単独の倍化点(β 1.00 / 1.74 / 1.90 rad、非周期 1.93)を、u = 1 / 2 / 3 / 6 に合わせた |
| 結合は非同期・瞬時の平均場 | 平均場を平滑化すれば更新タイミングの漏れは消えるが、GCM ではなく「共通の遅い駆動」になる。漏れは消さずに測る(README) |
| D:Lyapunov 指数で駆動される慣性つき歩行 | 周期域(λ<0)ではカオスへ、カオス域では押し戻される。ばね 1.0 / 押し 0.25 では張り付いた。ばね 0.1 / 押し 1.0 で歩くが、カオスの縁に集まり、手の R はほとんど効かない |
| D の駆動は写像そのものの λ(結合の ln(1−ε) を含めない) | 含めると強い結合が「秩序」に見え、R を R=4 の壁へ押し続けた |
| 出力に 5 Hz の直流カット | 非対称なインデックスで直流が乗る。線形フィルタなので周波数を足さず、周期も崩さない |
| 初期値:seed から R=3.99 の写像を (音番号 + 7) 回反復し、不動点からの小さなずれにする | 乱数を使わない。同じ鍵は同じ初期値。R>3 では不安定な不動点から離れていく過程が「サブハーモニクスが育つアタック」になる |

## 判定基準について

- 段を「耳で数えられる」のは 2 → 4 → 8 まで。周期 16 は −37 dB で R 幅 0.0009。
- 分岐図を見ながら回す本人は次の段を知っているので、聞こえる前に「聞こえた」と補いやすい。
  `bunki blind` で、画面なし・順番の分からない聴取ができる。
- 周期の違うボイスを結合すると、同期は(同音高でない限り)起きない。相のラベルは決め打ちせず、
  クラスタ数・切替率・同期率を測って出している(`tests/bunki_test.c` の 5.)。
