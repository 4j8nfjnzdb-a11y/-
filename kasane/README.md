# Kasane 重ね

映像の素材をレイヤーとして重ね、時間に沿って動かす道具。After Effects の系譜にあるレイヤー＋キーフレームの合成を土台に、
**音をいくつもの視点で読み分けて動きと結ぶ仕組み**（合わせる・逆らう・裏切る）と、**同じ操作を自分の結果にくり返して絵を変え続けるプロセス**を中心に据えている。

- `index.html` をブラウザで開けば動く（ビルド済み・依存なし。動画書き出しのときだけ Mediabunny を CDN から読む）
- `app.html` は Claude の Artifact 用の本体（`downloads` 権限で保存する）

## きっかけと調べたこと

出発点は、アドビのクリエイターストーリー「動きの哲学 × 映像の実験室」で児玉裕一氏が After Effects について語った一節 ——
素材ひとつひとつに直接触っている感覚、引きちぎることも、くしゃっと丸めることもできる、自分の机の上で作業しているよう、「ラボ」＝映像実験室。
（元ページは作業環境から開けなかったので、利用者の画面写真にある本文と、検索で確認できた範囲に基づく。）

### After Effects から引き継いだ骨格

| After Effects | Kasane |
| --- | --- |
| プロジェクト › コンポジション › レイヤー › プロパティ | 同じ階層。プロパティは「値ひとつ」か「キーフレームの列」 |
| 描画順：マスク → エフェクト → トランスフォーム | 同じ。エフェクトはレイヤー自身の座標で掛かる |
| 時間補間（リニア／ベジェ／停止）、イージーイーズ | 区間ごとの cubic-bezier、停止キー。イーズの初期値は 33% 相当 |
| 親子、ヌル、トラックマット、調整レイヤー、プリコンポーズ | すべてあり |
| 描画モード | 17 種（W3C の合成式） |
| モーションブラー（シャッター角度 180°） | シャッターが開いているあいだの変形を平均する |
| エクスプレッション（wiggle、loopOut …） | 同じ語彙の小さなインタプリタ（eval は使わない） |
| シェイプのパスのトリミング、テキスト、マスク | あり（線を描く・一文字ずつ・ペンでマスク） |
| パペットツール、モーションスケッチ | 「つまむ」（MLS 剛体変形）、●記録 |
| レンダーキュー | WebCodecs で 1 コマずつ正確に書き出し |

入れていないもの：3D レイヤーとカメラ、トラッキング、ロトブラシ／オブジェクトマット、テキストアニメーター、グラフエディター（イーズ曲線の編集だけある）。

### ブラウザで動く類似の道具

Pikimov（無料・レイヤー＋キーフレーム＋グラフエディター、Chrome/Edge のみ）、Jitter（Figma 風、テンプレート中心）、Rive（インタラクティブなベクター）、
SVGator、スマホの Alight Motion など。どれも「合成と動き」の道具で、音との関係を作品の構造として扱うものは見当たらなかった。

### 技術

- 合成は WebGL2。色は乗算済みアルファ、テクスチャは上が v=0 で統一
- 書き出しは WebCodecs + [Mediabunny](https://mediabunny.dev/)（MPL-2.0、書き出し時に CDN から動的 import）。なければ MediaRecorder で再生しながら録画
- WebCodecs は Chrome/Edge、Safari 26 以降、Firefox（デスクトップ）で使える。AAC を書けない環境では音は Opus になる
- 素材は IndexedDB、プロジェクトは localStorage に自動で残る。ファイルは端末の外へ出ない

## この道具に固有のところ

### 音を読む — いくつもの切り分け方を同時に

読み込んだ音は、どれかひとつを「正しい分解」とせずに、複数の視点から成分に読み分けられる（`src/sound.js`）。

- **大きさと帯域**：音量、低・中低・中・高、明るさ（スペクトル重心）、ざらつき（平坦度）、波形そのもの
- **打点**：スペクトル流束の山。全体と帯域別
- **P·M·V·R·S**：拍（P）、長い音・短い音（M）、速度感＝出来事の密度（V）、呼吸＝秒単位の音量とその増減（R）、無音とその長さ（S）。
  佐藤允彦『完全即興』が語法を手放したあとに残る要素として挙げる五つにならった切り分け（利用者の参照による）
- **予測と裏切り**：拍の格子を「聴き手が次に期待する打点」とみなし、予測された打点／予測になかった打点／来るはずだったのに来なかった打点に分ける。音色の変わり目も出す
- **色**：鳴っている音名を五度圏に置いた角度

タイムラインで音のレイヤーを開くと、成分が同じ時間軸の帯として見える。

### 関係 — 合わせる、合わせない、裏切る

どのプロパティも、成分のひとつと「関係」で結べる（プロパティの 〜）。関係には態度がある。

| 態度 | すること |
| --- | --- |
| なぞる | 成分にそのまま従う |
| 逆らう | 大きいときに引き、小さいときに出る |
| 溜めて放つ | 入力を溜め、いっぱいになったときだけ自分の間で動く |
| 数えて裏切る | 何度か従ってから次の一回を裏切る（黙る／逆へ／倍で／遅れて）。回数は固定・トゥエ・モース列・フィボナッチ語・サイコロ |
| 一歩ずつ | 打点のたびに次の位置へ進んで留まる（順／往復／黄金比／ばらばら） |
| 聴かない | 音の拍の無理数倍で、いつまでも揃わない自分の拍を打つ |

加えて「ずらし」（負なら音より先）、「先ぶれ」（打点の前から立ち上がり、打点の瞬間に届く）、立ち上がりと余韻、しきい値、曲がり。
音の代わりに**数列**とも結べる：トゥエ・モース列、フィボナッチ語、ふるい（剰余類の和と積）、ユークリッド、素数、ロジスティック写像、セル・オートマトン、酔歩、サイコロ。

解析も関係も、コンポジション全体について先に計算しておく。だからスクラブしても書き出しても同じ結果になり、絵が音より先に応えることもできる。

### 規則 — 結び方そのものを変える

「拍が 8 回来るたびに、結んである源を隣どうしで交換する」のように、音や数列の出来事をきっかけにして関係を曲の途中で組み替える
（源の交換・向きの反転・乱数の振り直し）。素材 → 視点 → 関係 → 方法 → 規則、という段のいちばん上にあたる。

### うつろい — 自分の結果にくり返す

| エフェクト | 規則 |
| --- | --- |
| とろけ | 絵が、絵自身の明暗と輪郭から読んだ流れに沿って動く。色ではなく「どれだけずれたか」を持つので、ぼけず、動画は溶けたまま再生され、戻す力も掛けられる |
| しずむ | 隣どうしの画素が順序を比べて入れ替わる（奇偶転置ソートを 1 コマに数回）。何も足さず、絵の画素だけが沈殿していく |
| くずれ | 各画素に x → r·x·(1−x) をくり返す結合写像格子。r は絵の明暗から読むので、静止・点滅・混沌の領域に分かれる |
| こだま | 前のコマを少しずらして重ね続ける |
| たたむ | 折る・回す・拡げる、を小数回まで連続的にくり返す |
| 走査 | 走査線に描き直し、明るさと音の実際の波形で線を揺らす |

状態を持つものはレイヤーの最初のコマから積み上げ、巻き戻すと控えから計算し直す。

### 手ざわり

ちぎる（なぞった線で二枚に裂く。同じぎざぎざを共有するので合わせ目が合う）、つまむ（ピン）、くしゃ（面に割れて丸まり、裏の白が見える）、
はためき、シールのふち、紙の質感、●記録（つかんで動かした手の動きをキーフレームに）、二本指での移動・回転・拡縮。

## 構成

```
src/util.js      行列・イージング・色・乱数・RDP
src/model.js     プロジェクト／コンポ／レイヤー／キーフレーム、1 時点の評価（Frame）
src/expr.js      エクスプレッションのインタプリタ
src/sound.js     音の解析、数列、関係、規則、方法
src/gl.js        WebGL2 の土台と共通シェーダー
src/effects.js   エフェクト（シェーダー／メッシュ変形／プロセス）
src/raster.js    文字・図形・マスク・ちぎり目の 2D 描画、書体
src/render.js    合成（マスク→エフェクト→配置→描画モード）、プロセスの状態
src/state.js     選択・履歴・コマンド・動きの型
src/media.js     素材の読み込みと保存、動画の同期、音の再生とミックス
src/export.js    動画・静止画・プロジェクトの書き出し
src/ui.js viewer.js timeline.js inspector.js main.js   画面
```

- ビルド：`./build.sh`（`src/` → `app.html` → `index.html`）
- テスト：`node tools/test.mjs`（モデル・式・音の解析・関係。ブラウザ不要）

## いまの限界

- m2ts は読めない（ブラウザが再生できる動画だけ）
- 入れ子のコンポジションの中の音は、再生・書き出しに混ざらない
- 動画レイヤーに状態を持つプロセスを掛けて途中から見ると、追いかけ計算のあいだは「いまのコマ」を入力に使う（最初から再生・書き出しすれば正確）
- 拍の検出は拍のある音を前提にしている。拍のない音では「P 拍らしさ」が下がり、拍に基づく成分は弱くなる
