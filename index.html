各フェーダー横の 🎲 でそのパラメータだけをランダム化。フェーダー左のチェックを外すと、⚄ / RANDOMIZE ALL / AUTO ではそのフェーダーが変わらなくなります（LOFI と d.fbck は最初からチェックなし。チェックを入れるとランダムの対象になります）。source の「l.fine」はループの長さを ±500ms の範囲で細かく調整します（中央付近ほど細かく動き、ダブルタップで0に戻る）。各トラックの ⚄ でトラック全体をランダム化。「RANDOMIZE ALL / GLITCH」で全トラックのパラメータを一気に揺さぶる。各トラックの FOLDER でフォルダを割り当てておくと、隣の 🎲📁 でそのトラックだけ新しいサンプルに差し替え、下の「RANDOM SAMPLES」で複数トラックのサンプルをまとめて差し替えられる（LOAD の単体選択はそのまま使えます）。● REC は全体のミックスを1つの音声ファイル（mp4 または webm）として保存します（Artifact 画面でも使えます）。● WAV REC は全体＋track1〜4 の WAV 5本を同時に録音し、停止すると ZIP 1つにまとめて一括保存し、下にそれぞれの試聴プレイヤーが出ます（ZIP を展開すると WAV 5本）。音が出ない時は 🔧 DEBUG を押すと、音声エンジンの内部状態が文字で表示されます。🔊 TEST TONE は、トラックの仕組みを一切通らない単純な音を1秒鳴らして、そもそも端末から音が出るかどうかだけを確認します。「0️⃣ RESET FX」は全トラックのリバーブ(depth)とディレイ(d.time / d.fbck / d.mix)のフェーダーを一括で0に戻します。その右のメーターは全体ミックスのL/Rレベルを視覚的に表示するものです（操作はできません）。
